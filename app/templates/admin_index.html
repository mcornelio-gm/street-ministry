Ministry Admin Guide

Use this dashboard to manage site content, outreach routes, and visitor messages:

  • Inbox — View visitor comments, questions, stories, and prayer requests. Click an email or phone number to reply, Copy for a plain-text copy, Mark Read/Unread to update the footer badge, or Delete to remove it.
  • Announcements — Post updates and urgent notices. You can Pin an announcement to the top or mark it Urgent.
  • Stories, Guides, Teams & About — Click New … or Edit to write in Markdown with a live preview. Keep stories privacy-first (first names or pseudonyms only).
  • Routes — Add or edit outreach routes and stops. Street addresses and cross streets are geocoded automatically, and you can drag map pins into place.
  • Share QR Code — Set a custom destination URL (like a short link) for the site’s QR code, or leave it blank to use the Home page URL.
  • Publishing — Saved changes are stored in Cloud Storage and go live on the site within a few seconds.
